Privacy Policy

Last updated 24 October 2026

This policy covers the personal hockey tools built around this site: a schedule sync that writes game times into a Google Calendar, and a video tool that uploads game film to YouTube. They are private utilities written for and used by a single person, Alex Albano. They are not products, they are not offered to anyone else, and no one else signs in to them.

What the tools do

  • Schedule sync. Reads publicly published league schedules from stats.panthers.timetoscore.com and creates or updates the matching events on the owner's own Google Calendar. Nothing is read from the calendar except the events the tool itself created, which it tags so it can recognise them.
  • Game film. Uploads the owner's own recorded games to the owner's own YouTube channel, and sets the title and description of those uploads.

What data is accessed

Google account data is accessed only through Google's official APIs, using access the account owner grants to their own account:

  • Google Calendar — to create, update and delete the hockey game events this tool manages.
  • YouTube — to upload videos and edit their titles and descriptions.

No contacts, email, files, location or profile information is requested or accessed.

Where it goes

Nowhere. The tools run on the owner's own computer and talk directly to Google. There is no server, no database and no third party. Nothing is sold, shared, transferred or used for advertising, analytics or training. Google account data is never used for anything beyond the calendar and upload functions described above.

Credentials

The OAuth tokens that authorise this access are stored only in local files on the owner's own computer and are never transmitted anywhere except to Google. Access can be revoked at any time from the Google Account permissions page at myaccount.google.com/permissions, which immediately and permanently stops all access.

This website

The pages on this site are static and publish only publicly available league statistics. The site sets no cookies and asks for no personal information. Aggregate, anonymous page-view counts are collected through GoatCounter, which records no cookies and no personal data.
